# Telegram Bot Moderator

Telegram-бот модератор для автоматической модерации чатов с использованием фильтрации нецензурных выражений, логирования действий и сохранения статистики в базе данных PostgreSQL.

## Возможности

- 🔍 **Фильтрация нецензурных выражений** - автоматическое обнаружение и удаление сообщений с нецензурной лексикой
- 🗑️ **Удаление сообщений** - автоматическое удаление нарушающих правила сообщений
- 🚫 **Блокировка пользователей** - автоматическая блокировка пользователей при превышении лимита предупреждений
- 📝 **Логирование действий** - полное логирование всех действий модерации в базу данных и файлы
- 📊 **Статистика** - сохранение статистики по пользователям и действиям модерации
- 🐳 **Docker поддержка** - готов к запуску через Docker и docker-compose

- Python 3.12+
- Docker и Docker Compose

- Telegram Bot Token (получить у @BotFather)

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository_url>
cd VCc02_TG_Moderator
```

### 2. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env` и заполните необходимыми данными:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Telegram Bot Configuration
BOT_TOKEN=your_bot_token_here

# Database Configuration (AlwaysData PostgreSQL)
DB_HOST=example.host
DB_PORT=5432
DB_NAME=db_name
DB_USER=user
DB_PASSWORD=your_password_here

# Bot Settings
LOG_LEVEL=INFO
LOG_FILE=logs/bot.log
```

### 3. Настройка базы данных

База данных PostgreSQL уже должна быть настроена. Бот автоматически создаст необходимые таблицы при первом запуске:

- `moderation_actions` - логирование действий модерации
- `user_stats` - статистика по пользователям
- `message_logs` - логи всех сообщений

### 4. Запуск через Docker Compose

```bash
docker-compose up -d
```

Для просмотра логов:

```bash
docker-compose logs -f
```

### 5. Запуск без Docker (локально)

```bash
# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python bot.py
```

## Использование

### Добавление бота в группу

1. Создайте группу в Telegram или откройте существующую
2. Добавьте бота в группу
3. Назначьте бота администратором группы (важно!)
4. Выдайте боту права на удаление сообщений и блокировку пользователей

### Команды бота

- `/start` или `/help` - показать справку
- `/stats` - показать статистику модерации (только для администраторов)
- `/ban <user_id>` - заблокировать пользователя (только для администраторов)
- `/unban <user_id>` - разблокировать пользователя (только для администраторов)

### Настройки модерации

В файле `config.py` можно настроить:

- `DELETE_MESSAGES` - удалять ли сообщения (по умолчанию: `True`)
- `BAN_USERS` - блокировать ли пользователей (по умолчанию: `True`)
- `WARN_BEFORE_BAN` - количество предупреждений до блокировки (по умолчанию: `3`)

### Фильтр нецензурных выражений

Список нецензурных слов можно настроить в файле `src/filters/profanity_filter.py`. 
В реальном проекте рекомендуется хранить список в базе данных для удобного обновления.

## База данных

### Таблица `moderation_actions`

Логирует все действия модерации:

- `id` - ID записи
- `user_id` - ID пользователя
- `username` - имя пользователя
- `chat_id` - ID чата
- `action_type` - тип действия (message_deleted, ban, unban и т.д.)
- `reason` - причина действия
- `message_text` - текст сообщения (если применимо)
- `moderator_id` - ID модератора (если действие выполнено вручную)
- `created_at` - время создания записи

### Таблица `user_stats`

Статистика по пользователям:

- `id` - ID записи
- `user_id` - ID пользователя
- `username` - имя пользователя
- `chat_id` - ID чата
- `warnings_count` - количество предупреждений
- `deleted_messages_count` - количество удаленных сообщений
- `banned` - заблокирован ли пользователь
- `last_action_at` - время последнего действия
- `created_at` - время создания записи

### Таблица `message_logs`

Логи всех сообщений:

- `id` - ID записи
- `message_id` - ID сообщения в Telegram
- `user_id` - ID пользователя
- `username` - имя пользователя
- `chat_id` - ID чата
- `message_text` - текст сообщения
- `is_deleted` - удалено ли сообщение
- `created_at` - время создания записи

## Логирование

Бот логирует все действия в:

1. **Файл** - `logs/bot.log` (настраивается в `.env`)
2. **Консоль** - при запуске без Docker
3. **База данных** - все действия сохраняются в таблицы БД

## Разработка

### Структура модулей

- **config.py** - настройки приложения через переменные окружения
- **src/database/connection.py** - подключение к PostgreSQL и работа с БД
- **src/logger/logger.py** - настройка системы логирования
- **src/filters/profanity_filter.py** - фильтрация нецензурных выражений
- **src/moderation/moderator.py** - основная логика модерации
- **bot.py** - инициализация бота и обработчики сообщений

### Добавление новых фильтров

Для добавления новых типов фильтров создайте новые классы в `src/filters/` и интегрируйте их в `src/moderation/moderator.py`.

## Устранение неполадок

### Бот не удаляет сообщения

- Проверьте, что бот добавлен как администратор группы
- Убедитесь, что у бота есть права на удаление сообщений
- Проверьте логи: `docker-compose logs -f`

### Ошибки подключения к базе данных

- Проверьте правильность данных подключения в `.env`
- Убедитесь, что база данных доступна из сети
- Проверьте, что порт не заблокирован файрволом

### Бот не блокирует пользователей

- Проверьте, что у бота есть права на блокировку пользователей
- Убедитесь, что `BAN_USERS=true` в конфигурации
- Проверьте логи на наличие ошибок
